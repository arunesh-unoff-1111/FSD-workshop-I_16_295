# Authentication Dashboard

A simple React + Vite authentication project with Sign Up, Login, Dashboard, and Logout functionality.

## Features

- Sign Up
- Login
- User details dashboard
- Logout
- Responsive UI
- LocalStorage for user data

### Signup → Login → Dashboard → Logout → Login
